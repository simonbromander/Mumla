# Mumla Mac Beta 1.0.1 (33)

- Adds Check for Updates in the menu bar and Settings for direct Mac builds.
- Updates use a signed HTTPS feed and signature-checked, notarized downloads.
- No background update checks, analytics, or silent installation.
- Installation waits for recording, transcription, pasting, and model downloads
  to finish. Local history, dictionary, settings, and models are preserved.
- The first updater-enabled build requires one manual installation.
- Requires macOS 14 or later; Apple silicon and Intel are supported.

This is a beta. Real hotkey and cross-app paste behavior still needs verification
on the target Mac with Input Monitoring and Accessibility granted. The updater
does not bypass permissions or change transcription/paste behavior.
